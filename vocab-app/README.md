# 魔法词本 V0.5（试验版）

把你在哈利波特英文版里积累的词汇，做成手机上能随时翻看的小词本。

> 本版本先不做艾宾浩斯复习，只做：**导入词表 → 手机查看 → 搜索 / 筛选 / 排序**。

## 你怎么在 iPhone 上用

1. 用 Safari 打开上线后的网页（合并 PR 并开启 GitHub Pages 后可用）
2. 点底部分享按钮 → **添加到主屏幕**
3. 主屏幕会出现「魔法词本」，通勤时像 App 一样打开

当前仓库里还没有你的那份 ~1000 词 HTML。你可以：

- 在 App 里点 **导入 HTML**，直接从手机/电脑选择文件；或
- 把 HTML 发给我 / 上传到仓库，我再帮你把解析规则调到完全匹配

## 本地运行

```bash
cd vocab-app
npm install
npm run dev
```

浏览器打开终端提示的地址即可。

## 导入格式建议

最稳的是表格：

| 单词 | 音标 | 释义 | 频次 | 标签 |
| --- | --- | --- | --- | --- |
| corridor | /ˈkɒrɪdɔː/ | 走廊 | 58 | 四级 六级 |

也支持一行一个：`word — 释义`

标签里写「四级 / 六级 / 高考」会被自动识别，用于筛选。

可参考：`vocab-app/public/sample-import.html`

## V0.5 已有功能

- 词汇列表（演示 30 词，可被你的 HTML 替换）
- 搜索（单词 / 释义）
- 筛选：全部、高频、四级、六级、高考、其他
- 排序：频次高低、A-Z
- 词条详情（音标、释义、例句、标签）
- 导入后保存在本机浏览器（localStorage）
