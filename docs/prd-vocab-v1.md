```text

联系：A 更新后 B 刷新词条；LearningState 必须按 wordId 保留
```

## 3. 场景 → 功能

唯一用户：本人（手机）。

| ID | 场景 | 用户目标 | V1.0 功能 |
| --- | --- | --- | --- |
| S1 | 打开 App 开始今天的学习 | 先清旧词，再学新词 | **今日**首页；先复习队列再新学队列；一次一词；三档反馈 |
| S2 | 复习以前学过的词 | 按间隔把到期词再练一遍 | 到期复习（目标约 50～75）；记得/模糊/忘了 → 更新下次时间 |
| S3 | 学习新词 | 每天消化一批未学词 | 新学 30；高频×考试标签加权后随机 |
| S4 | 读书时查一个词 | 快速确认释义 | **词库**搜索/筛选/详情（默认录入序） |
| S5 | 词库又录入了新章节 | 手机里能看到新词，旧进度还在 | 词库版本刷新；按 wordId 合并；进度不丢 |
| S6 | 换机或清了缓存 | 学习进度还在 | 进度在数据库（实现另议） |

**V1.0 不做的场景/功能：** 发音朗读、查询历史、一键复制、进度统计页、账号体系。

## 4. 信息结构 + 主业务流

### 4.1 信息结构

```text
Lumos
├── 今日（首页 · 主入口）
│   ├── 今日概览（待复习数 / 待新学数）
│   ├── 复习会话（一次一词）
│   └── 新学会话（一次一词；复习告一段落后进入）
├── 词库
│   ├── 列表（默认：录入顺序）
│   ├── 搜索 / 筛选 / 其它排序
│   └── 详情（只读查询，无认识快捷操作）
└── 我的（极简，可后置）
    ├── 词库版本说明
    └── 必要设置（额度自定义等可 V1.x）
```

### 4.2 主业务流（先复习后新学）

```text
打开 App
  → 落在「今日」首页
  → 拉取/生成今日队列
       ├─ 复习队列 = 已到期 LearningState（目标约 50～75）
       └─ 新学队列 = 未学词中按权重随机抽 30
  → 若复习队列非空：
       进入复习卡片（一次一词）
       用户选：记得 / 模糊 / 忘了
       写回 LearningState.dueAt 等字段（数据库）
       直到：达今日复习目标 / 到期已清 / 用户暂停
  → 再进入新学卡片（一次一词，默认 30）
       展示英文 → 看释义 → 确认进入学习
       创建 LearningState，安排首次复习时间
  → 返回今日概览（可显示剩余，但不做独立「进度看板」页）
```

规则要点：

- **复习优先于新学**；未完成复习时，不把新学当作默认第一步  
- 到期复习不足目标：有多少刷多少  
- 到期复习超过上限（建议默认 75）：先刷上限，剩余顺延（细则可再补）

## 5. 分页面说明（入口 / 操作 / 反馈）

### 5.1 今日（首页）

| 项 | 说明 |
| --- | --- |
| **入口** | 打开 App 默认进入；底栏/导航「今日」 |
| **展示** | 今日待复习数量、待新学数量；主按钮进入当前应做的会话（有复习则先复习） |
| **操作** | 开始复习 / 开始新学（仅当复习已完成或为空时突出新学）；可暂停返回概览 |
| **反馈** | 完成一张卡片后数量减少；队列结束给简短完成提示 |
| **不做** | 发音、复制、查询历史、学习曲线/统计大盘 |

#### 5.1.1 复习卡片（一次一词）

| 项 | 说明 |
| --- | --- |
| **入口** | 今日 → 开始复习 |
| **操作** | 查看当前词；选择 **记得 / 模糊 / 忘了**；进入下一词 |
| **反馈** | 选项提交后立即进入下一词或结束；进度写入数据库 |
| **备注** | 卡片内更细文案/是否先藏释义，可继续补充 |

#### 5.1.2 新学卡片（一次一词）

| 项 | 说明 |
| --- | --- |
| **入口** | 今日在复习告一段落后 → 开始新学 |
| **操作** | 一次一词学习；确认后计入已学并进入复习日程 |
| **反馈** | 写入 LearningState；今日新学剩余减一 |
| **抽词** | 未学池中，高频 × 四/六级/雅思加权后随机 30 个 |

### 5.2 词库

| 项 | 说明 |
| --- | --- |
| **入口** | 导航「词库」 |
| **展示** | 词列表；**默认排序 = HTML 录入顺序（entryOrder）** |
| **操作** | 搜索；按标签等筛选；切换其它排序（频次、A-Z…）；点进详情 |
| **反馈** | 列表随搜索/筛选更新 |
| **详情** | 音标、释义、标签、备注等；**无「认识/不认识」** |
| **不做** | 发音、复制、查询历史 |

### 5.3 我的（极简）

| 项 | 说明 |
| --- | --- |
| **入口** | 导航「我的」（可后置到 V1.x，若 V1.0 要发版也可先做空壳+版本号） |
| **展示** | 词库版本等信息 |
| **不做** | 学习进度看板、打卡商城、账号 |

## 6. 数据对象

### 6.1 `wordId`

- 每个词条的专属身份；**全局唯一、不可重复、长期稳定**  
- **不等于** HTML 章内序号，也不等于 `entryOrder`  
- 一经分配，改释义/改排序/调整章节都 **不得更换**  
- LearningState 只通过 `wordId` 关联  

### 6.2 `WordEntry`（词条 · 来自轨道 A）

| 字段 | 说明 |
| --- | --- |
| `wordId` | 唯一稳定 ID |
| `entryOrder` | 录入顺序；词库默认排序依据 |
| `word` | 英文词或短语 |
| `phonetic` | 音标（展示用；V1.0 不要求发音播放） |
| `meaning` | 中文释义 |
| `frequency` | 书中出现相关频次（新学加权用） |
| `tags` | 如四级/六级/雅思/专四/专八等（新学加权与筛选用） |
| `chapter` / `note` / `inflection` 等 | 章节与备注类信息（按现有 HTML 能力保留） |

词库刷新：更新 WordEntry 内容；按 `wordId` 对齐；**不得清空** LearningState。

### 6.3 `LearningState`（学习进度 · 存数据库）

| 字段（逻辑） | 说明 |
| --- | --- |
| `wordId` | 关联词条 |
| `status` | 如未学 / 学习中 / …（实现时可细化） |
| `dueAt` | 下次复习时间 |
| 间隔相关 | 如 easiness / interval / repetitions（简化 SM-2 类） |
| `lastReviewedAt` / 最近反馈 | 记得/模糊/忘了 |

约束：

- **必须持久化到数据库**（不因清缓存/换机丢失；接入另议）  
- **不需要前台进度展示页**  
- 仅用于生成今日复习/新学队列与写回调度结果  

### 6.4 今日队列（可每日重算，不必长期当独立表）

- `reviewQueue[]`：当日到期 `wordId` 列表（裁剪到约 50～75）  
- `newQueue[]`：当日新学 `wordId` 列表（默认 30）

## 7. 验收清单（V1.0）

- [ ] 打开 App 默认进入 **今日**（主入口）  
- [ ] 有复习时 **先复习、后新学**  
- [ ] 复习 / 新学均为 **一次一词**  
- [ ] 复习三档 **记得 / 模糊 / 忘了** 并影响下次到期  
- [ ] 复习量级按约 **50～75** 组织；新学默认 **30**  
- [ ] 新学抽词体现高频与四/六级/雅思倾向，并带随机  
- [ ] 词库 **默认排序 = HTML 录入顺序**  
- [ ] 词库详情 **无**认识/不认识快捷操作  
- [ ] 每词有唯一稳定 **`wordId`**，不与排序号混用  
- [ ] 学习进度在 **数据库**；词库升级后进度仍在  
- [ ] 前台 **无**学习进度展示页  
- [ ] V1.0 **无**发音、查询历史、复制  
- [ ] 产品呈现名为 **Lumos**（若未再改名）  
- [ ] iPhone 上可完整走通上述流程
